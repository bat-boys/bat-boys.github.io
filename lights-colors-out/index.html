Starting state

Instructions

This is a solver for BatMUD gala quest puzzles Lights Out and Colors Out.

You'll have to set the starting state which can be clicked from first column buttons, or copy-pasted into second column textarea.

Then you'll have to set all the five moves that pressing each cell will do.

Then click solve and hope for the best.

Starting state and moves are stored in URL, so you can copy the URL for continuing later. Browser's back and forward work as undo and redo for edits through mouse clicks (not for typing the moves via keyboard).

For questions, comments and bug reports, contact astrax in the game or in discord.
